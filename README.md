# Triple Espresso

//Descripcion del proyecto
Se trara de una landing page interactiva para una cafetería llamada Triple Peaks. 
El sitio permite a los usuarios conocer la filosofía de la marca, consultar horarios de atención, ubicar la sucursal y realizar reservaciones de mesa a través de un formulario validado.

//Tecnología usada//
Tecnologías usadas:
HTML5 Semántico: Uso de etiquetas como <header>, <main>, <section>, <nav>, <fieldset> y <footer> para garantizar una estructura accesible y bien organizada.
CSS3 (Posicionamiento y Diseño): Implementación de técnicas avanzadas de posicionamiento (absolute, relative) para elementos decorativos y composiciones visuales complejas.
Tipografía Web: Integración de fuentes personalizadas como Inter y Noto Serif con sus respectivas familias alternativas para optimizar la experiencia de lectura.
Interactividad: Aplicación de estados dinámicos (hover) en elementos clicables como enlaces y botones para mejorar la respuesta al usuario
